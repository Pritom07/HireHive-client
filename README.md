# 🐝 HireHive – Job Portal Website

HireHive is a **full-stack job portal application** built using the MERN stack.  
It provides a platform where recruiters can **post jobs and manage applications**, while job seekers can **apply for jobs and track their application status**.

---

## 🚀 Features

### 👤 For Job Seekers
- View all available job postings
- Apply for jobs with details
- View your submitted applications
- Track your application status (Pending, Selected for Viva, Hired, Rejected, etc.)

### 🏢 For Recruiters
- Post new job opportunities
- View all your posted jobs
- See the list of candidates who applied for your jobs
- Update application status (Hired / Pending / Rejected / Selected for Viva)

---

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS, DaisyUI, React Router  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Authentication:** Firebase  
**Others:** Axios, REST API
